This post is an example and a guide at the same time. To add a new blog post:

1. Create a new file in `src/content/blog/` with a `.md` extension, for example `my-new-post.md`.
2. Add a frontmatter block at the top, between two lines of three dashes, with a title, summary, date, author, and tag.
3. Write the rest of the post below the frontmatter using normal Markdown: headings with `##`, bold with `**text**`, links with `[text](url)`, and lists with `-`.
4. Save the file and commit it. The post appears on the blog automatically, newest first.

You can delete this post once your team is comfortable with the format.
